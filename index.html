About Me

Born and raised in a mid-sized city in the islands of Central Philippines, I grew up witnessing how technology could bridge gaps and transform lives. This inspired my journey as a data scientist and developer, where I've built AI-powered solutions leveraging geospatial, demographic, and shopper data. I have also led product strategy across Southeast Asia and ANZ, driving impactful business and consumer outcomes. I am privileged to have had a diverse set of experiences, having lived, worked and played football in 5 (and hopefully counting) cities.

Projects

  • GeospatialPythonMapLibre

    Metro-Mapping

    Open-data pipeline that delineates the functional metro area of any Philippine city on an H3 hex grid. Combines OpenStreetMap establishments and roads, WorldPop population, and a CBD-connectivity rule to produce a reproducible built-up footprint, calibrated against GHSL and validated on held-out cities. Ships as a static web map.

    Live map GitHub
  • GenAIFastAPINext.js

    ALTO

    Skyline view synthesis for real estate and urban planning, built for the SG DeepMind Hackathon. Pick an address, storey, heading, and time of day; ALTO stacks Street View, satellite, and elevation context, derives a deterministic lighting profile, and prompts Gemini to render what the view would look like before it exists.

    GitHub
  • GeospatialWeb app

    Where PH

    Web app that uses a geospatial join to map a set of coordinates to detailed location information (village, city, province). Includes an authentication and credits module enabling batch upload for registered users. Saved 100+ labor hours across multiple area mapping projects.

    GitHub
  • Python packageOptimization

    Scipy Optimstruct

    Python package that simplifies defining variables and constraints for optimization problems with the SciPy optimization module, making it easier to organize and solve structured problems.

    GitHub PyPI
